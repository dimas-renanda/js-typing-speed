# js-typing-speed (⌨️ Typing Speed Test)

A simple, fast, and responsive typing speed test built with **HTML**, **CSS**, and **JavaScript**. Practice your typing, improve your speed, and track your accuracy in real time.

## ✨ Features

- 🚀 Real-time typing test
- 📊 Live Words Per Minute (WPM)
- 🎯 Live accuracy tracking
- ⏱️ Automatic timer
- 📝 Random typing quotes
- ✅ Character-by-character highlighting
- 🔄 New quote generation
- 📱 Responsive design
- 🎨 Modern glassmorphism UI
- ⚡ Built with pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/dimas-renanda/js-typing-speed.git
   ```

2. Open the project folder.

3. Run `index.html` in your browser.

No installation or dependencies are required.
